# Duo Fold Live 3.5.3-alpha.11

Based on alpha.10. Keeps the fixed physical panel mapping, outgoing labelled screenshot and uncovered live incoming app. Glass remains disabled in this diagnostic mode.

- Removes the three-second task placement/focus verification timeout that released concurrent mode even when the incoming app looked correct. Placement and focus are now separate diagnostics; an unavailable diagnostic query also does not release the session or retry routing.
- Adds a three-second hold checkpoint with task and window traces. Endpoint, screen lock/off, stale-angle, physical-panel readiness and Android cancellation handling remain. The 30-second session limit is checked before readiness waits.
- Adds a second **Copy status without health history** button. It copies the same report except for the 24-hour health samples; the original full-report button remains available.

Validation: CI runs unit tests, lint, release build and signature/alignment verification. Separate task placement/focus observations have a regression test. On-device delayed-blackout behavior still needs testing; Android endpoint cancellation and fold sleep may still cause a blackout.
