# 3.5.3-alpha.8 — labelled screenshot and window/power trace

Diagnostic continuation of ci-116-1. No discarded old alpha.8 code is included.

With both screenshot toggles ON, outgoing snapshots carry two magenta FROZEN COVER / FROZEN INNER labels baked into their pixels. Each label includes a frame suffix, logical capture display, physical-ID suffix and source dimensions. The status report records full capture identity and the overlay destination identity at screenshot frame commit. A label travelling to another screen therefore identifies the frozen image rather than relying on Home layout resemblance.

Both displays' task configurations are recorded before requests, once the secondary reports ON, before requested release, and approximately 200/1200 ms after release while polling continues. Read-only, filtered window dumps run on a bounded background queue with a 1.5-second timeout; requested and actual collection timestamps make scheduling delays visible. Four snapshots are retained. No task, focus, power or lock setting is changed by diagnostics.

App-side power/keyguard observations are retained during the hold and for five seconds after release, plus screen-off/on/user-present broadcasts. These samples are separate from software display states and cannot establish optical continuity.

Incoming glass remains omitted and incoming content remains uncovered. Activation timing, endpoint release, rotation and wake policies are unchanged. This is not a fix for the stretched launcher or final black interval.

## One-cycle test
Install over ci-116-1; keep animation and both screenshot toggles ON. Return to cover Home; unfold slowly once, then fold once, and promptly copy the normal status report. Note which physical screen displays each magenta label, and whether the distorted content is labelled. No new video is required, though a recording with the labels is useful. The normal status and lifecycle sections plus Screenshot panel trace and Screenshot power/keyguard events suffice; the 24-hour health samples are not needed.
