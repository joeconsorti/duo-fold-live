# 3.5.3-alpha.8

## Live handoff routing fix

- Fixes the first real Developer blackout-free handoff report from alpha.7.
- Alpha.7 successfully enabled the developer preview and destination prewarm, but normal app stacks repeatedly failed with `No task matches focused cover root`.
- Samsung can expose a focused root that wraps the actual visible app task during concurrent fold states. The old router incorrectly required both child-task membership and an exact root/top-activity match.
- The live router now selects the actual top standard task on logical display 0 by exact top-activity match when available, with a safe fallback to the first standard visible task on that same primary display.
- Home routing behavior remains separate and unchanged.
- A failed live handoff is now attempted only once per hinge movement. The preview will not repeatedly hammer task routing until the device returns to a folded or unfolded endpoint.
- No new test screen. Continue testing through the normal animation with **Blackout-free handoff · DEV PREVIEW** enabled.
- Default behavior remains unchanged; the developer preview is still OFF by default.
