# Alpha.63 reconstructed — animation rotation hold

Version code 1316. Private candidate based on alpha.62; recovery target remains
alpha.20. No GitHub publication or original-source equivalence is claimed.

Only requested changes: remove Reverse direction (normal gyro direction in both
modes) and repair rotation ownership during animation. Hold/resume tolerances stay
5 degrees; hold time stays 1.25 seconds. Quality, blur, glass and startup unchanged.

The old rotation policy treated pause/disabled as a block that only an endpoint
could clear. Mid-fold resumption therefore left rotation unlocked. An initial
disabled heartbeat and a 30-second cutoff could also suppress a later active hold.
The new policy re-arms on fresh enabled animation at any partial angle. Fresh
animation renews the hold; stale reader data still releases it after the existing
bounded grace, and the journal/owner-death recovery remains intact.

Rotation stays held through the live unwind and Duo's retained scene/dissolve.
After the scene is removed or at endpoints, the temporary overrides restore the
user's saved rotation preferences. Resuming takes a fresh orientation snapshot.
Manual device rotation lock is preserved, not overridden by enabling auto-rotate.

Each physical panel keeps its captured orientation even when Samsung swaps logical
display IDs. Previously the outgoing primary was no longer protected when it
became display 1. Reassert fixed-to-user policy on the primary as well as the
secondary, including when Samsung changes policy without changing identity.
Unknown secondary displays are never modified without saved restoration data.
The existing verified fixed-policy release now also covers the coordinated path.

Tests cover pause/unwind/dissolve/resume for both modes, the unchanged 5-degree
boundary, fresh/stale heartbeats, endpoints, off/keyguard/thermal/probe gates,
all saved panel orientations across remaps and orientation changes while paused.
Android API compilation, existing controller/renderer/recovery checks and release
audits supplement these tests. No handset is connected; physical rotation behavior
and OEM callback timing require device testing. Software lock readback is not
proof of pixels remaining stationary.

Build and package with tools/build_local_test.py from a clean committed tree;
preserve APK and complete source archive together before delivery.
