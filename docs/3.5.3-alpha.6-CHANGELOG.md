# 3.5.3-alpha.6
- Continues from alpha.5, which proved both physical panels can remain ON with repeated mirror/native-underlay toggles and no black-screen power cycle.
- Adds a focused native-task handoff experiment for the cover-to-inner direction.
- While CONCURRENT_OUTER_DEFAULT keeps both panels alive and the live cover mirror remains visible on the inner panel, tap **Move focused task to live inner display**.
- Duo requests the currently focused cover task on display 1, verifies that it is actually placed and focused there, then automatically removes the mirror only after native inner content is confirmed.
- Adds **Finish handoff: release cover hold**. This cancels the concurrent outer-primary request only after the native inner task is already live, allowing the normal cover shutdown to occur after content handoff instead of before it.
- If the test is stopped before commit, Duo attempts to restore the moved task to the cover. After Finish handoff, the inner placement is intentionally retained.
- This is still a developer-only diagnostic. Normal animation behavior and stable main remain unchanged.
