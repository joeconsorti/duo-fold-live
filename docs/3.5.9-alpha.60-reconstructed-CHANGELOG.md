# 3.5.9-alpha.60 reconstructed — Screenshot mode promotion candidate

- Screenshot Mode now selects the coordinated app-snapshot renderer tested in
  alpha.59, with Windowed Glass enabled and the existing blur/stretch controls.
  The old screenshot route and long-press unlock are no longer selectable.
- Live Screen is available in both private and release builds. Its live capture
  and animation are restored from the private screenshot-baseline restrictions.
- Both modes use the shared hold-to-settle behavior: hold for 1.25 seconds;
  below 90° selects cover, above 90° selects inner, exactly 90° keeps the active
  panel. The selected panel stays latched through jitter; 5° movement resumes.
- Existing Screenshot users migrate to the tested renderer. Existing Live Screen
  users keep Live Screen. New installations retain Live Screen as the default.
  Switching modes preserves the selected animation style and appearance controls.

The coordinated renderer, app movement/readiness, Home preparation and endpoint
release are unchanged from alpha.59. There is no speed/time veto on animation.

This candidate uses reconstructed source; equivalence to the original recovered
target (alpha.20) is not established. Public publication is pending thermal
follow-up: the supplied alpha.59 report reached Android thermal status 2 during
the short repeated-fold test. See the reconstruction notes for evidence limits.
