# Duo Fold Live 3.5.9-alpha.66-reconstructed

Adaptive resolution now reduces animation detail when Android reports thermal pressure, then restores it in stages as thermal status clears.

## Changes

- Adaptive resolution is on by default, with an optional off toggle directly below the effect resolution slider.
- At thermal status 1 or higher, the next animation drops straight to 25% per dimension. At status 0, the cap rises to 50%. Ten uninterrupted minutes at status 0 restore the selected maximum. Renewed thermal pressure resets the timer.
- The resolution slider remains the maximum. Disabling adaptation uses that selection; it does not erase thermal recovery history.
- Both Duo panels keep one effective resolution throughout a coordinated animation, including display handoffs. Resolution changes apply between animations.
- New-install/reset defaults: 100% effect resolution, 50% glass strength, 75% blur. Existing saved settings are preserved. Use Reset resolution if the slider still holds a previous 25% test setting.
- Diagnostics report the selected maximum, effective session resolution, thermal cap and recovery time; each fold-health row records its effective resolution.

## Validation and limitations

Local alpha.66 passed 570 debug unit tests. GitHub CI tests the release variant, runs lint and renderer/controller checks, audits the output, and signs the attached APK before publication. Thermal behavior and visible continuity still need handset verification; software measurements are not optical proof.

A service restart preserves the cooldown. If the entire app process ends during recovery, the next process conservatively restarts the ten-minute recovery after thermal status clears. No wake lock is acquired for the cooldown.
