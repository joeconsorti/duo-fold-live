# Duo Fold Live 3.0.3

- Fold 7 wallpaper setup selects video_002.mp4; Fold 8/Ultra retains the existing video_001.mp4 profile.
- Unknown models can select Fold 7 or Fold 8/Ultra during setup. The choice is saved and included in connection reports.
- Setup verifies both Home wallpaper bindings against the selected profile and reuses matching installed profile settings when available.
- Existing animation, fades, rendering, custom photo wallpaper, and lock-screen bindings are unchanged.

For existing Fold 7 installations, open Connection & setup → Show setup → Repair required wallpaper setup.

Android 17 remains required for automatic wallpaper setup. Android 16 support is not included. Fold 7 regional firmware and Ultra-specific wallpaper assets still need device validation; model recognition is not a guarantee of compatibility.

Validation: 167 unit tests and release lint passed before release preparation; CI repeats tests, lint, APK build and signature verification.
