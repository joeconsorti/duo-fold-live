# 3.0.4-alpha.20

- New unset/reset defaults: motion smoothness 30 ms, blur amount 30%, glass strength 50%. Existing explicit preferences remain saved.
- Blur amount and glass strength now follow motion smoothness, above black fade controls, each with its own reset button.
- Live capture defaults to 120 FPS (experimental); 60 FPS is labeled lower GPU cost. Each capture checks the current source display refresh rate and caps the requested rate accordingly, including 60 Hz mode and display remapping. This does not change Android display settings. Actual capture throughput remains device-dependent.
- Center-edge blur offset replaces the old width control: 7% beyond the fold by default, adjustable 0–15% of full inner display width. Uses a fixed feather up to 5% wide. The old width preference is intentionally separate from the new location setting.
- The glass shader extends its existing progressive blur across the hinge, removing the independent constant blur floor that could pop on at the start of folding. Inner-preview feather uses its existing frosted image and follows hinge progress to zero at fully open.
- Retains support reminders and the corner-alignment fix from prior builds. Wallpaper flash remains partly resolved.

Automated checks cover display-rate caps, offset bounds, feather continuity, motion onset and smoothing. Visual alignment and adaptive-refresh behavior require device confirmation.
