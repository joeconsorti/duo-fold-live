# Duo Fold Live 3.5.9-alpha.65-reconstructed

This pre-release promotes the alpha.65 candidate confirmed working by the tester on
SM-F971U / Android 17 on October 29, 2026. It includes the intervening local alpha
development since the previous public alpha.6 release.

## Changes

- Duo Mode is the default folding animation style. Live Screen Mode (Legacy) remains available.
- Windowed Glass is the standard effect. Plain Fade, Duo Classic and the reverse-direction toggle have been removed.
- Both styles share the glass, blur, motion controls and 25%, 50%, 75% or 100% effect resolution setting.
- Hinge pause restores an interactive screen after holding still; animation resumes after 5 degrees of movement. Animation rotation holds are released when the effect ends or pauses and reacquired on resume.
- Duo Mode starts faster and supports multi-window workspaces.
- Alpha.65 fixes workspace wallpaper composition and cross-panel clipping. With custom wallpaper enabled, it captures each selected app window independently and composes the wallpaper once underneath, preserving pane alpha and avoiding captured transition/dim layers.
- Workspace composition diagnostics now collect images when explicitly armed.

## Validation and scope

The tested source passed 558 debug and 558 GitHub release unit tests, release lint
and assembly, plus workspace capture, Home capture, buffer ownership, controller,
task, power, brightness, scene and shader checks. The tester confirmed the alpha.65
visibility fix. This is not verification of every device, app or folding sequence;
software readiness and compositor captures are not optical panel measurements.

The isolated workspace capture path requires the enabled custom wallpaper host.
Missing or secure panes, ambiguous window groups, changing geometry and timeouts
reject the entire capture and use existing native recovery. The previously observed
intermittent brightness preparation timeout was not changed by alpha.65.

## Installation and provenance

The APK attached here is the regular GitHub app (`org.duofold.live`), signed through
the existing GitHub release workflow. It is separate from the private local Test
app (`org.duofold.live.test`); settings from that Test app do not transfer automatically.

This release remains labelled **reconstructed**. It contains maintained recovered
source and subsequent fixes, not a claim that the original missing source or its
exact behavior was recovered. The application source matches tested local commit
`9f530badf75641aaea900817667d7ba0f00d1a66`; publication adds release documentation and replaces device identifiers in one test
fixture with synthetic labels. Private recovery diaries and device reports are
not included in the public source tree.
