## Current evidence and correction

The supplied alpha.100 session 923548566 starts at the cover, reverses several
times without an endpoint, and then holds around 127–128 degrees for several
seconds. Alpha.99/100 incorrectly froze pause eligibility to the last endpoint's
screen. That gate excludes this hold despite fresh stationary observations.
Restore the earlier angle-selected return: below 90 cover, above 90 inner,
exactly 90 the active panel, selected when the hold completes. Early D0 remaps
and old endpoints cannot veto it. Continued hinge progress still restarts the
1.5-second timer, including one-degree-per-second motion; time spent folding
alone cannot trigger the hold. Only the selected native panel is parked.
After completion, crossing 90 changes the native panel without restarting the
animation. The endpoint clears the latch for the next leg. The optional
five-degree resume setting and legacy-route behavior remain.

The first alpha.100 session 923541106 ends at 133 degrees after 2316 ms; its
early controller events are absent from the pasted report tail. A brightness
fallback is a plausible explanation for the snap, not a demonstrated cause.
Historical alpha.97/99 brightness failures are not current-build evidence.

Independently, the source contains an abrupt native-fallback release path.
Direct software recovery at a partial fold now reverses the retained effect
and dissolves it after fresh native readiness. It does not request a panel,
renew power, take a new capture, or extend the existing 1800 ms recovery limit.
Endpoint, Android cancellation, lock, disable and thermal release rules remain.

## Reverse animation

The per-panel 280 ms unwind advances only after an accepted completed buffer
frame, with at most 32 ms of animation progression per completion. A delayed
first delivery or GPU gap cannot consume the animation offscreen. In-flight
duplicates and obsolete request callbacks cannot advance it. The starting pose
is frozen from the latest committed angle; the ordinary glass shader receives
the reverse pose for both its angle and progress inputs. Native dissolve is
gated by the selected panel's completed final return frame and current native
window readiness. Completion callbacks remain software evidence, not photons.
The 160 ms native dissolve follows the unwind; blocked rendering can lengthen
the unwind within the existing bounded return deadline.
