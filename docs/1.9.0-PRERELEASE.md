# 1.9.0-alpha.1 — pre-release

Version code 1014. This is not a main/stable release.

## Fade controls

Animation settings now expose independent black fade smoothing (0–120 ms, default 24 ms) and gradualness (0–100%, default 35%). Changes persist and apply without restarting the service. Reset restores both defaults.

Gradualness 0 preserves the previous 10-degree approach band and 180 ms reveal; 100% uses 40 degrees and 500 ms. Default is 20.5 degrees and 292 ms. The existing 98-degree opening and 94-degree closing handoff thresholds remain unchanged. Angle smoothing is reversible and must reach full black at the handoff threshold. The destination still waits for continuous ON and a matching draw after the 120 ms settling interval, with the existing bounded draw-readiness fallback.

## Performance work

- Fade updates follow Choreographer display callbacks; an 80 ms fallback keeps OFF-period supervision alive when VSYNC stops.
- Unchanged alpha, stack, and crop values no longer submit duplicate compositor transactions.
- Display reflection fields are cached; fade status and formatted angle reports update at most four times per second.
- Angle polling targets a 4 ms completion-paced period instead of 1 ms. Urgent handoff requests remain immediate, with no overlapping polls or catch-up bursts.
- Routine secondary display refreshes are capped at one per 8 ms; display event paths remain immediate.
- Existing half-resolution glass rendering and requests for up to 120 Hz remain enabled by default.

These changes reduce unnecessary work. They do not prove 120 displayed FPS. Hardware testing is required to measure actual frame pacing, power consumption, and Samsung display policy behavior. No handset is attached to this build environment.

## Device check

Use normal folding with continuity test off. Check both directions, slow movement, rapid movement, reversal near the handoff angle, and lock/unlock. Try gradualness at 0%, 35%, and 100%; confirm incoming display starts black and reveals the original animation. Report connection diagnostics and a description/video if either direction flashes or stays black. Actual Samsung physical OFF intervals still exist.
