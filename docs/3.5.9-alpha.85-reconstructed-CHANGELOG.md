# Alpha.85 local handoff update

This build changes the trigger for the primary screen switch in Duo Mode on the independent-layer route used by the SM-F971U. Opening selects the inner screen and closing selects the cover. The saved handoff angle remains available in Advanced for routes that use it.

* The first switch can proceed as soon as both presentations are mapped, the currently active physical screen has committed its own captured image, and brightness preparation and initial writes have succeeded for both panels. Duo rechecks the physical primary, its power state, the current fold direction, and the app's timestamped presentation acknowledgement immediately before requesting the new primary. A retained stationary image qualifies while the app continues to confirm that same image and mapping.
* Home, workspace and regular app folds use the same readiness trigger. For a regular app, Duo moves the selected task under committed coverage. A destination capture can arrive during preparation or after Android remaps the primary. If a prewarmed image has different dimensions or rotation after the remap, Duo captures it again on the verified primary. The controller keeps coverage while it verifies the destination image and native window readiness.
* A 5° movement back from the furthest angle reached identifies a reversal. Small movements around that point keep the current direction. A reversal before a switch cancels obsolete preparation. A reversal after the switch goes through a fresh brightness and outgoing-image check. The separate stationary-hinge pause and native endpoint handling still apply.
* Missing brightness evidence or a rejected brightness write returns control to Android. The old Home timeout no longer authorizes a forced switch. The trace records READINESS_HANDOFF with the actual request angle, outgoing physical screen and frame-commit timestamp.

The source image acknowledgement comes from Android's completed buffer and visibility transaction. Handset pixel visibility, physical blackouts and end-to-end speed have not been measured on this build. Install over alpha.84 to retain the saved settings.
