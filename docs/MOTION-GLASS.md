# Motion glass experiment — 3.5.7-alpha.7

Developer settings → Motion glass → Motion-driven glass. Off by default. Live Screen only; screenshot mode and static settings previews retain their previous behavior.

Alpha.3 replaces alpha.2’s small texture translation with an inverse geometry warp before projection, stretch, blur, and shading. Sideways tilt expands/contracts the projection from the fixed left edge; the other tilt axis skews it progressively away from that edge. Alpha.5 corrects inner anchoring: the inner left edge moves freely while the clean right half/seam stays fixed. This also applies to the reflected cover preview on the inner display. Only the actual cover pins its left edge. The reflected cover preview compensates for its canvas flip when choosing its anchor. Existing neutral geometry is unchanged, including with motion disabled or response zero.

Controls: enable, reverse direction, projection response (0–200%, default 100%), smoothing (0–300 ms, default 90 ms), recenter, reset tuning. The new projection-response preference deliberately does not reuse alpha.2’s small image-shift value. Alpha.4 reverses direction by default (Reverse motion direction starts ON) and halves sensitivity. The slider is renormalized: 100% is the new gentler default, equivalent to alpha.3 at 50%; 200% is equivalent to alpha.3 at 100%. A 30-degree tilt at the default gives approximately 1.414x/0.707x cover scale. Vertical skew is additionally halved so horizontal distortion dominates. Upgrade resets only motion direction and response once; subsequent changes persist. Reset motion tuning uses the same new defaults. Inner geometry expands/contracts from the seam without moving the clean reference half.

Sensor sampling requests approximately 60 Hz. The first fresh rotation-vector sample after leaving a fold endpoint establishes neutral; the reference persists through primary-display handoff unless the service stops the effect. A sensor gap over 500 ms re-establishes neutral. Recenter is available during a partial fold.

Uses the non-wakeup game rotation vector, with rotation vector fallback. This is simulated viewpoint motion, not gaze tracking or translation measurement. No system rotation settings, hinge values, handoff thresholds, captures, or permissions are changed. Sensor updates redraw existing captures. Sensors stop at fold endpoints, with feature/animation off, on stale hinge input, screen off/lock, or service destruction. Unsupported sensors leave the original effect intact.

Validation: tools/check_motion_projection.py compiles the actual shared shader warp and checks zero-tilt identity, the cover left anchor, inner seam anchor and free left edge, clean inner half, all display rotations and reflected canvas, bounded monotonic inner geometry, and opposite tilt directions. Existing inner-stretch and shading checks remain in CI.

Handset acceptance: use a detailed wallpaper or grid, enable motion, partially open and hold the hinge still, then tilt left/right and up/down. Check that the cover left edge stays fixed and the inner left edge moves freely around its fixed seam. Check the clean right preview stays still, including through handoff. Repeat while closing, in each display rotation, with reflected preview enabled. Test reverse direction, response zero/max, smoothing zero/max, recenter, full endpoints, and lock/stop. Share the usage report. Automated checks do not establish physical sensor direction, visual quality, or handset handoff latency.

Existing Repair auto-rotate resolved the owner's rotation issue. No rotation-policy patch is included. Main/stable and Play remain unchanged. The separate stock-handoff diagnostic app remains deferred until this experiment is tested.

Alpha.6: actual cover motion mapping is reversed independently; primary inner and reflected inner glass keep their alpha.5 mapping. Reverse motion direction now defaults OFF, with a one-time direction-only reset on upgrade. Sensitivity/smoothing are preserved. Tilt remains linear beyond 30 degrees and clamps at 60 degrees instead; sensitivity near neutral is unchanged. At default response the maximum cover scale becomes 2x/0.5x; at 200% it is 4x/0.25x. Anchors remain unchanged.

Alpha.7: on reaching fully open with live inner motion glass, retain the last rendered distortion and ease the shared geometry amount to zero over 300 ms. The renderer and host use the same clock; gyro samples are held during the return instead of immediately zeroed. Full-open display-policy release remains unchanged. Screen-off/lock, disable, stale hinge input and service cleanup still clear immediately. Refolding cancels the return and resumes sensing. Reports record return start/completion/interruption. Test fast and slow reopen from a strongly squashed inner view, then refold during the return and test lock/disable. Main/stable and Play remain unchanged.
