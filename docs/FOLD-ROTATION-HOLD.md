# Temporary fold orientation hold

Separate worker in the angle-reader process. No rendering or fade changes. Uses primary-display freezeDisplayRotation (display 0), with rotation captured before the transition. Samsung concurrent secondary rotation follows the primary in DisplayRotation.shouldRotateSeamlessly. Temporarily holds each settable posture through the system API so mapping changes cannot briefly reload auto-rotate. Rechecks lock status at most every 100 ms and reasserts after physical mapping changes. Endpoint settlement is 450 ms; lease 1000 ms; maximum continuous hold 30 seconds, after which an endpoint is required to rearm. This bound avoids locking a device left half-folded indefinitely.

Firmware inspected: user-supplied SM-F971U Android 17 framework.jar and services.jar. IWindowManager provides freezeDisplayRotation(int,int,String), thawDisplayRotation(int,String), isDisplayRotationFrozen(int), getDisplayUserRotation(int), setDeviceStateAutoRotateSetting(int,boolean). DeviceStateAutoRotateSettingController posts rotation changes asynchronously and warns against direct writes to accelerometer_rotation / device_state_rotation_lock. Restoration therefore uses the per-device-state Binder API, matching PostureDeviceStateConverter property routing (16 rear, 11 outer, 12 inner, 2 half-open), then verifies the saved posture map. The existing user_rotation value is restored separately. Unknown or missing posture maps fail before freezing; the connection report explains why.

An atomic journal is saved before the freeze. A process-held file lock prevents another helper from undoing a live hold. Endpoint, screen lock, stale input, disable, and stop restore it. The independent keep-awake service checks abandoned journals; reconnect/start also recovers them. If Shizuku is unavailable, privileged restoration must wait until it returns. A failed readback retains the journal and retries. No signing changes.

Release restores Android auto-rotate behavior. If the phone is already tilted on release, Android may rotate immediately; this feature does not add a new post-transition sensor gesture requirement.
