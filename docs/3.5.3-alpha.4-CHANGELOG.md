# 3.5.3-alpha.4
- Developer-only Camera continuity diagnostic now displays real primary-screen content on the secondary panel, using an isolated compositor mirror.
- Optional frozen snapshot: select the checkbox, start, then tap Show Home; captures once five seconds later. Snapshots stay in memory and are not saved.
- Start fully closed and unfold, then repeat starting fully open and folding. Keep animation OFF. Check visual continuity, live updates, and full-closing behavior. Return to the diagnostic to copy its report.
- Secondary content is center-fitted and read-only. This does not yet transfer native app layout, touch, navigation, or normal animations.
- Preserves the successful window-first concurrent-state request. Stops on the 30-second deadline, lock/screen-off, physical mapping change, normal animation reactivation, or helper/app connection loss. Leaving via Show Home explicitly permits the bounded background test; ordinary page exit still stops it.
- No new normal-use toggle or automatic activation. Main release remains unchanged. Cover/inner compression defaults remain 90%/40%, with the existing per-build Advanced animation reset.
- Full-closing primary-switch blackout remains; this diagnostic does not yet add a transition fade.
