## Code defects addressed

1. The renderer previously submitted changing-angle buffers while an earlier
   commit callback was pending. A remap also cleared that pending flag, allowing
   more work before the old submission drained. Both panels draw on the main
   thread, so this could amplify buffer pressure and delay both animations.
   Alpha46 permits one outstanding acknowledged submission per window and
   consumes the newest hinge pose after its callback. Invalidation cancels the
   old frame's readiness evidence without opening the submission gate. Obsolete
   callbacks cannot retire or acknowledge a replacement. An actually destroyed
   Surface cancels its pending ticket immediately, so its missing callback cannot
   delay a replacement Surface. Other missing callbacks use the existing 500 ms
   retry bound. This is pacing, not proof that buffers have
   been released; a slow driver or compositor can still stall a canvas call.
2. Pre-promotion reversals formerly cleared the scene immediately while restoring
   a task that could still be on secondary display 1. They now restore native
   policy/task under retained coverage, require new native geometry and repeated
   window readiness, and keep the existing fixed 1,800 ms fallback. No additional
   screenshot shield or concurrent-state request is made for the return.
3. Cleanup formerly published session=0 before task restoration, power release,
   or pending shield removal completed. It now withdraws the scene after those
   operations finish. Lock, disable, lost-heartbeat and 30-second app-side bounds
   remain in force. The timeout path may still release without verified native
   readiness; it is reported as a timeout, never as a verified handoff.
4. Presentation acknowledgement fields now travel as one immutable snapshot.
   A single unmask decision cannot combine a physical ID from one callback with
   native-image/animation flags or commit timestamps from another callback.
5. Normal and canceled native-readiness decisions refresh their clock after
   blocking layout queries. A successful callback arriving during such a query
   no longer looks future-dated relative to the tick's old clock. Genuinely
   future-dated, stale, mismatched and competing-task results remain rejected.

No remap-time screenshot recapture, live mirror, Home task selection, increased
power hold, or weakened both-panel preparation gate was introduced. The alpha45
fade, independent late-animation skipping and saved visual controls remain.
Diagnostics add coalescedDraws, pendingAgeMs and commitTimeouts per window.
