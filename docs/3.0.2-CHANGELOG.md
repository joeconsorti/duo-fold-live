# Duo Fold Live 3.0.2

Setup recovery and compatibility fixes:
- Fix fresh installs skipping the wallpaper/permissions wizard because startup defaults were mistaken for existing user setup.
- Reopen setup on update for previously skipped installs with no verified wallpaper setup; interrupted setup resumes. Completed setups remain saved.
- Route animation enabling through setup when overlay access or accessibility is missing.
- Show wallpaper repair and connection reports directly when connected but receiving no fresh angles.
- Explicit wallpaper repair reapplies both HOME bindings even if the saved configuration already matches.
- Add Shizuku+ releases links and uninstall-original-first guidance in initial setup, troubleshooting, and connection settings. Use wireless/USB ADB mode.
- Make Shizuku launch/authorization feedback visible, preserve wallpaper action messages, and clarify accessibility restricted-settings instructions.
- Update setup helpers with each app version; add bounded setup timeout/retry and clearer root-mode guidance.
- Accept identifiable internal panels with other resolutions for secondary animation and fallback photo layers, including Ultra-sized panels.
- Include firmware and angle-reader counters in connection reports.

The approved animation/fade design is preserved. Custom wallpaper selections remain saved. Existing 3.x users can install over their current version using the same signing key.

Limitations: Android 17 and compatible Samsung FoldInteractive wallpaper/APIs remain required. These fixes do not establish full Fold 6/7/Ultra or regional firmware compatibility. Zero-angle failures on affected firmware still require on-device verification. Existing unlock wallpaper flash, occasional fade issue, and orientation-lock limitations remain under investigation.
