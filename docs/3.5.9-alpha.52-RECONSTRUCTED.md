## Changes

- Home's cross-panel placeholder uses the same centered fill/crop for backdrop,
  clipping and glass sampling. This prevents conflicting contain/fill geometry.
  It remains a temporary cropped source layout, not a fabricated native destination
  layout; the existing guarded native Home capture replaces it after remap.
  Same-panel Home and every app retain their prior sampling/layout behavior.
- Home captures use a separate Binder operation (9), with the same existing exact
  task/display/geometry checks plus focused fullscreen Home identity before/after.
  Explicit fading window alpha, entrance/exit animation or destruction rejects
  the candidate. Missing alpha fields are unmeasured, not asserted opaque. This
  cannot detect all launcher child-view animations or prove icons are present.
  There is no new fixed delay, pixel heuristic, stale image cache or task move.
  Rejected Home bitmap ownership is released, including thrown post-capture checks.
- Arming the existing six-fold diagnostic now gives Home an INNER-PANEL-ONLY
  sequential recorder instead of four sparse stage attempts. Ordinary app
  diagnostics retain their old path. The physical inner identity is followed
  across D0/D1 remaps; logical slot is resolved and checked on every capture.
  Captures continue for up to one second after app-side scene cleanup, independent
  of whether a renderer still has a valid commit. OFF/unstable/failed frames are
  recorded as missing, not replaced by a repeated successful image.
- Target interval is 125ms (8 samples/s), <=320px on the longest side. One frame
  is in flight; no catch-up queue. Moving budget is 240 attempts / 12MiB, with a
  separate 8-attempt / 2MiB tail budget and a 32-second overall bound. PNG writes
  and metadata happen off the UI thread. Native window observations occur at
  most every 750ms, never on every sample. Diagnostic overhead can still change
  timing; unarmed Home comparisons remain necessary.
- Each sequence saves numbered physical PNGs, source thumbnails, timestamps,
  raw hinge angle, renderer pose/commit/source metadata, stage, physical/logical
  mapping, capture interval, failures and sampled Home window details. Metadata
  is sequential evidence, not synchronized comparisons. An offline review.html
  viewer plays using recorded request intervals, supports scrubbing/stepping,
  and leaves unavailable frames visibly missing. Extract the ZIP first.
- New capture requests reject locked state, non-Home/non-Recents focus, cover-panel
  geometry and changed focus/mapping. They never request protected capture or
  alter layers. New sessions, rearming and clearing invalidate in-flight results.
  Home animation works without arming any diagnostics.
