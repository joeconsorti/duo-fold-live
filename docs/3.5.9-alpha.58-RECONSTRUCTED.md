# 3.5.9-alpha.58 reconstructed local — settle on a stationary hinge

mode promotion, GitHub push, or public release. Recovery target remains alpha.20;
reconstructed source does not establish equivalence with the original source.

After one second within a two-degree stationary band, the effect unwinds over
280 ms. Live Screen and the current coordinated screenshot mode both use the
same sensor-time gesture. Opening returns to the source cover screen; closing
returns to the source inner screen. Four degrees of new travel rearms the
gesture at the current pose. Repeated IPC responses cannot manufacture a hold;
sample gaps restart observation. Disable, lock, stale input, mode changes and
physical endpoints clear the gesture. Explicit continuity diagnostics keep their
existing timing instead of engaging this gesture.

toward the selected panel's neutral pose; saved glass, blur, compression, stretch
and ordinary handoff settings are unchanged. There is no new speed/travel/startup
veto. Alpha56's early Home preparation and endpoint bypass remain in place.

physical panel under existing coverage. Home stays under native launcher task
management. A new physical/geometry/readiness token and repeated native-window

not a new bitmap. Ordinary moving-handoff capture/readiness guards are unchanged.
