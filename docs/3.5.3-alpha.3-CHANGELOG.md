# 3.5.3-alpha.3
- Optional Camera-style continuity test in Advanced → Developer settings.
- Turn animation off. Start fully open (inner-primary) or closed (cover-primary), then observe the second screen and slowly fold/unfold. Choose moving or frozen test imagery. Copy the dedicated test report.
- Follows Samsung Camera's window-first order and equivalent named concurrent states/flags. Uses an app-permitted overlay window rather than Camera's privileged window type.
- Diagnostic only: does not move ordinary apps, reproduce all animation styles, or claim the native-primary blackout is fixed. A failed window attachment/request is reported without forcing display power.
- Stops after 30 seconds, leaving the page, lost heartbeat, helper/app death, or detected primary mapping change. Exit can still flash.
- Future compression defaults: cover 90%, inner 40%. Existing once-per-build Advanced animation reset applies; other settings retained.
