# Alpha.83 reconstructed local — restore earlier handoff behavior

VersionCode 1336. Based on alpha.82 plus its source audit. This is a targeted
restoration requested after the audit, not a complete rollback to alpha.51 or a
claim of verified blackout elimination. Recovery target remains alpha.20.

## Changes and evidence

1. Restore Home's alpha.51 primary-request timing using the existing saved
   handoff +/-20 degree band. At the reported 85-degree setting, opening requests
   inner at 105 degrees and closing requests cover at 65 degrees, subject to the
   existing preparation gates. Alpha.56 had advanced Home's first request to
   20/152 degrees. The latest alpha.82 traces place requests 112–730 ms after
   initial presentation callbacks and OFF callbacks shortly after three of those
   requests. This removes that early Home scheduling shortcut. It does not remove
   the native primary exchange or prove the firmware power transition is gone.

2. Restore the physical-ID/layer-stack assignment decision from alpha.51 commit
   95b41538df3a646605102badfa7dc1a308f50a68. Remove alpha.80's requirement to wait for
   logical geometry/rotation and a second pair of DisplayInfo reads before the
   exchange. The audit reproduced wrong-root/black-backing exposure when physical
   routing had already switched but logical geometry lagged, matching the mixed-row
   shape in the latest trace. Missing IDs and duplicate IDs/stacks remain rejected.
   Both roots exchange together; completion still gates mapping readiness. Current
   bar-crop reset, pause dissolve, lease bounds and safe guard teardown are retained.

3. Preserve saved Advanced animation controls on the specific alpha.82-local
   1335 to alpha.83-local 1336 upgrade. Otherwise the existing per-build migration
   would reset handoff angle, stretch, compression and related values, confounding
   the restoration comparison. Update the migration marker without removing keys.
   New installs and other upgrade paths keep their existing migration behavior.

The preserved alpha.51/52 release notes contain positive reports for alpha.50 slow
folds and alpha.51 ordinary-app folding. They do not establish flawless Home.
Home capture, wallpaper composition, shader settings, buffer producer, ordinary
app handoff thresholds, workspace timing, physical hinge guard, rotation cleanup,
brightness and endpoint power tails are not changed by this build.

## Known limits and tradeoff

The source audit recommended against treating a bare mapping rollback as a general
solution. This release follows the subsequent request to restore prior behavior,
pairing that restoration with Home's earlier handoff timing and retaining explicit
tests for its limitations. It introduces no speculative compositor API or new
power mechanism.

The two-order replay shows that alpha.51-style mapping handles geometry that lags
actual routing, but can map too early when metadata leads physical routing.
Alpha.83 retains that known limitation. A successful restoration replay means the
old behavior was recovered, not that both race orderings are solved. DisplayInfo
is not atomic with compositor routing. A screenshot cannot conceal actual panel
OFF. Neither the replay nor transaction completion is optical proof.

Home's native destination layout now starts later. A fast fold may reach its
endpoint before a fresh destination capture arrives; the existing immediate Home
endpoint release remains in force. There is no added image hold or extended timer.

  directions, restored Home boundary, unchanged ordinary-app boundary, reversal

- Scene harness: 28 mapping/cleanup checks; brightness: 52; task routing: 60;

- Historical physical-routing replay supports a candidate revision and compares
  its results with alpha.51 in both orders, including the known failing order.
- Full Android unit tests, lint, APK identity, signing certificate and final file
  hashes are recorded in the accompanying build manifest after packaging.

No handset is connected. Install as an update to the existing local test package;
uninstalling is unnecessary. Existing alpha.82 controls are preserved for this
comparison. Evaluate the same Home and ordinary-app open/close motions on both
panels; alpha.83 is a restoration candidate, not a verified public release.
