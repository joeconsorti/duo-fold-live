# Duo Fold Live 3.5.9-alpha.2

Adds **B8 Display Lab (experimental)** under Advanced → Developer settings.
It is off by default and has no launcher icon. Enable it, then tap **Open B8
Display Lab** to access the manual tests, including Test B8 from Lab 0.5.11.

This is the proven timed test embedded in Duo, not yet an automatic hinge-driven
replacement for Duo's animation. Turn **Enable animation** off before starting
a recording. Hold near 90 degrees, authorize/connect Shizuku, select Test B8 and
the starting panel/app, and save the report ZIP afterward. Re-enable normal
animation after the test finishes.

The B8 mirror, brightness hold/preparation, geometry verification and task-alias
fix are preserved. The existing Lab controls remain available. The occasional
brief flash has not been tuned in this release. Previous reports of a compositor
restart during mirror tests remain relevant; this release does not claim that
failure resolved or universal app compatibility.

The observer has its own Shizuku helper process; its bounded cleanup watchdog
does not terminate Duo's angle-reader helper. Report files and notification IDs
are separate. Starting a test is refused while Duo animation is enabled; turning
animation on or disabling the lab during a recording requests test cleanup.

Retains the 3.5.9-alpha.1 stale-angle handoff fix. Does not replace main/stable.
This public pre-release uses the existing Duo signing key for in-place updates.
Developer settings hide the controls from the normal flow, not from determined
users; the APK and source are public.

Validation: engine baseline comparison, portable route/guard/recovery tests,
Android Java compilation, plus CI unit tests, lint, release audit and signature
verification. Handset behavior of the embedded build still needs confirmation.
