# 3.0.4-alpha.29

- Replaces alpha.28's AA wrapper, which evaluated the entire glass/blur shader four or seven times per pixel. The report showed 1.6 captures/s, stale prepared frames and canceled handoffs; this is consistent with rendering contention but does not establish a single device-level cause.
- Edge-Adaptive Smoothing now filters a rendered RenderNode layer through RenderEffect. Its neighbor samples read pixels, not the entire glass program. If the edge effect throws, that frame draws with the working lightweight path and logs the error.
- 4× Supersampling now doubles both render-buffer dimensions relative to the normal half/full-resolution choice. The compositor downsamples the resulting surface. Glass executes once per high-resolution pixel; the old multi-evaluation wrapper is removed from every mode.
- Starts everyone on the proven Lightweight mode through a new AA-method preference. Experimental modes remain selectable; the enabled toggle, strength and other settings remain saved. Frosted Reflection remains the default for unset reflection preferences.
- Reports include AA mode, enabled state and strength. Rendering errors include their message. Keep Awake and display-handoff policies are unchanged.

Higher-resolution buffers still cost GPU time and memory; on-device testing is required before promoting either experimental mode. Successful compilation alone does not verify Samsung animation behavior.
