# 3.0.4-alpha.28

- Frosted Reflection is now the default for an unset preference; explicit saved choices remain unchanged.
- Advanced offers three anti-aliasing methods: original Lightweight Texture Filtering, new Edge-Adaptive Smoothing, and new 4× Supersampling (default).
- Edge-Adaptive Smoothing detects local luminance/alpha contrast and blends samples across edges while preserving flat regions. This is a custom spatial filter, not branded FXAA or temporal AA.
- 4× Supersampling evaluates the full glass effect at four subpixel positions, including projection, texture and alpha coverage. Sample spacing accounts for the actual render-buffer scale on both half- and full-resolution settings.
- Both new modes retain the existing texture prefilter and bounded strength control. Disabling AA restores the prior unfiltered sampling path. Neither reconstructs detail absent from captured frames.
- Higher GPU cost is intentional for visual comparison. Both glass styles share the same AA implementation; no automatic quality switching is added. Native compositor mirrors and prepared frosted bitmaps are not postprocessed by this glass-renderer setting.

Candidate remains alpha pending device comparison before primary-release promotion. Keep Awake remains deferred and unchanged.

Validation: both complete glass shaders compiled with Skia RuntimeEffect. A diagonal-edge test produced partial-coverage pixels in both new modes (64 edge-adaptive, 43 supersampled) versus none with the unsmoothed reference. This checks sampling behavior, not Samsung GPU performance or subjective image quality.
