# Alpha.91 · First unfold after an angle gap

Alpha.90's first unfold in X recorded 923 ms for panel preparation, accepted the inner image around 2.13 seconds, and committed one native inner frame around 2.96 seconds. A 758 ms hinge-sample gap preceded the presentation lease failure.

A direct scene with submitted frames on both panels can report that it still holds those frames when its latest hinge sample is 750–1,999 ms old. This message carries the session and a fixed expiry derived from the last hinge sample. It supplies no primary, capture or readiness evidence. Fresh input and the usual destination checks are required for the handoff to resume. The existing lock, cancellation, thermal and timeout handling remains active.

With Windowed Glass enabled, the app prepares up to two independent glass shader programs in a background worker on service startup and replenishes them between sessions. Each panel takes one unused program, or uses its existing synchronous construction path on a miss. The app still constructs its physical roots and buffers at session time. Alpha.90's incoming frost and dissolve use the same render path.

## Handset comparison
