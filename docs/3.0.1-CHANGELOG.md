# Duo Fold Live 3.0.1

Compatibility-check-only update. Regional SM-F971, SM-F976, and SM-F966 families are recognized, including U, U1, W, B, B/DS, N, and 0 variants. Unknown model numbers now show a warning in setup and settings and are allowed to proceed.

Android 17 is still required. Existing Samsung wallpaper and API checks remain unchanged. This does not establish functional compatibility on untested devices. Animation, wallpaper backend, and other settings are unchanged from 3.0.0.
