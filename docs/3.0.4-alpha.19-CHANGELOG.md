# 3.0.4-alpha.19

- Live content capture targets 60 FPS by default. Advanced settings offer legacy ~12 FPS and experimental 120 FPS. Capture time counts toward the frame budget; diagnostics report measured capture throughput. Actual delivery depends on device capture performance.
- Main settings now include a blur amount slider, defaulting to 150%, with additional inner-display blur. Shared downsampled frames are prepared off the UI thread, retaining the existing bounded shader sampling cost.
- Advanced settings include a feathered center-edge blur width, defaulting to 2% of display width. The stationary strip extends beyond the fold into the right side in screenshot and inner-preview paths.
- Support the Project reminders start after 3 days of successful use, followed by gaps of 7, 14 and then 30 days, recurring every 30 days. Existing prompt history migrates once; updates do not reset the schedule. Snooze and permanent dismissal are preserved.
- Retains alpha.18's device-independent corner alignment correction. The partly resolved wallpaper flash remains a known issue.

Device validation is needed for measured capture FPS, visual seam alignment, blur preference and sustained thermal behavior. Screenshot mode intentionally remains static.
