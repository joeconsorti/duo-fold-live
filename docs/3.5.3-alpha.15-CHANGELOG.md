# Duo Fold Live 3.5.3-alpha.15

Based on alpha.14. Main remains 3.5.2. Keep the user's normal path (dual OFF, cover preview ON) and saved settings.

## Preview ordering fix

Alpha.14's log showed the handoff call preceding the queued pre-release preparation, including negative elapsed values. The old code blocked the hinge Binder call for 24 ms but then released regardless of whether the queued job had started; cleanup/no-layer also counted down the same latch as a commit.

Replace that latch with a request-local, nonblocking gate. Normal opening waits across hinge polls for a compositor transaction commit, a stated skip/failure, or an 80 ms total budget. No angle-thread sleep. A queued preparation that misses its deadline is skipped, and the submission path checks the deadline again after display queries. Stale/late callbacks cannot acknowledge a newer request. Reversal, stale data, disable, keyguard and the fully-open endpoint do not wait for the preview gate.

Request timestamps are captured before queueing. Logs identify request, queue/submission age, commit outcome, and handoff return relative to the same request. No negative duration caused by a subsequently initialized timer. Existing reactive preview coverage and fade duration remain unchanged. A compositor commit still does not establish optical presentation, and this does not eliminate firmware panel OFF.

## Closing investigation

Add a bounded normal-handoff event ring with the observed angle, requested/current/base state IDs, explicit cancel calls/returns and Android cancellation callbacks (including superseded request callbacks). The independent power trace samples current/base device state when panel/interactivity observations change. This lets the next report correlate the extra closing OFF pulse with state/cancel events. No new power API mutation or cancellation threshold change is introduced; the closing pulse is not claimed fixed.

Validation: CI tests, lint, release assembly, existing signing/alignment checks. New unit cases cover commit-before-release, deadline-before-queue, late callback, missing callback and skip-vs-commit outcomes. Local whitespace and inner-stretch checks passed. Phone validation required.
