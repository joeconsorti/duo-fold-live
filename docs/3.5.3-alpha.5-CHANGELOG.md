# 3.5.3-alpha.5 — native underlay test (alpha.4 restart)

Built directly from approved alpha.4 commit 19a9561. Discarded alpha.5–alpha.8 changes are not included. This is a new experiment using the available alpha.5 name; identify it by this release's CI tag.

## Test
1. Turn Duo animation OFF and open Advanced → Developer settings → Camera-style continuity test.
2. Fully close the phone. Select “Reveal native inner content 5 seconds after Show Home.”
3. Start the 30-second test, tap Show Home, then unfold within five seconds.
4. At five seconds, Duo removes its live image and makes its retained secondary window transparent. It keeps the same concurrent request and primary mapping. It does not move or focus tasks.
5. Observe: proper inner Home/taskbar or cover layout? Does touch work? Does either panel flash? Blank inner content is a valid diagnostic outcome, not proof of a panel power-off.
6. Return to the test page and copy the Camera test report. The normal timeout/lock/mapping-change/disconnect cleanup remains active. Test expiry or full closure may flash.

Original live and frozen tests remain available with the new checkbox off. The native reveal and frozen mode are mutually exclusive. A reveal is skipped if the live inner mirror is not ready. Read-only task/configuration snapshots are taken at reveal and shortly afterward.

Normal animation, shaders, wallpaper, rotation, settings defaults, and public main are unchanged. This tests whether native content already exists under the mirror; it does not yet implement native task placement or the blur transition. Device validation is required before integrating either.
