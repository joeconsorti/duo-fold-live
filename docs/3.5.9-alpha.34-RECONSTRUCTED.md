# Alpha34 reconstructed local

Based on alpha33 (7182ac55). User confirmed wallpaper contamination and fast-close blank/flash absent, but occasionally saw a miniature inner image on the cover.

- B8 geometry observations are reused across rendering, readiness and diagnostic calls. Display changes/removal invalidate observations; physical identity, mode dimensions and rotation key each entry. Valid ON measurements persist per physical configuration; OFF preparation can reuse them. Panel shape bookkeeping survives transitions.
- Surface buffers are sized before window attachment; identical layout callbacks skip redundant painter layout and buffer-size work. Actual window size, physical mapping, ON state, exclusions and app HAS_DRAWN remain mandatory. No fixed readiness delays were shortened.
- Cross-panel source placeholders center-crop to fill the destination instead of shrinking the whole source into a letterbox. Native-panel screenshots retain existing fitting and alpha33 pre-shield snapshot retention. A crop is temporary coverage, not a freshly relaid-out app.

No device-specific dimensions are hardcoded. No mirror, power, wallpaper or animation changes. Display ON is still required for window attachment; this build does not claim to eliminate Android surface allocation or app relayout time. Speedup and fast-close behavior require handset testing; software tests cannot prove optical continuity.
