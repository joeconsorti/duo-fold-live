# Alpha.100 reconstructed local — stillness, reverse unwind, native continuation

Version code 1353; based on alpha.99 cca08106da250d21e7a1cdd8f05848b65982ce83.
Includes alpha.97 pipeline/startup changes and alpha.98 per-panel software FPS.
Recovery target remains alpha.20. No handset or optical verification is claimed.

## Behavior and historical review

Reviewed the October 29 pause request retrieved from prior chat (smooth reverse
stretch/blur, no snap) and the checked-in alpha.78 pause notes/code. Alpha.78
explicitly resumed at a midpoint crossing; its code did not distinguish a
continuation from reversal. Alpha.99 kept that rule when it restricted eligibility
to the outgoing panel. The current user report specifically rejects restarting
the outer animation after a paused closing leg continues through 90 degrees.
This build corrects that path rather than claiming the prior notes specified it
unambiguously. Legacy mode midpoint behavior remains unchanged.

- Duo still requires 1.5 seconds of eligible observations on the outgoing side.
  Bounded jitter remains permitted, but extending the observed angle envelope
  by a sensor degree restarts the clock. Continuous 1-degree/second travel no
  longer passes merely because it fits inside a 5-degree band. Repeated replies,
  stale input and gaps retain their existing protections. Wallpaper receipts
  still cannot prove hardware sensor freshness or distinguish unreported motion.
- Default completed Duo hold remains native through the rest of this leg.
  Crossing 90 selects the other native panel without creating screenshots,
  renderers or a new animation session. Exactly 90 keeps the selected panel.
  Endpoint clears the latch; the next leg can animate. The explicit optional
  5-degree movement-resume setting remains available and unchanged.
- Independent moving renderers start a frozen-pose 280 ms unwind on their first
  drawable frame, not on the shell's earlier restoration request. Task/display
  remap delays cannot consume that animation before its first draw. Native
  dissolve requires a completed final-unwind callback for this session, request
  and physical primary, in addition to the existing native readiness checks.
  The 160 ms dissolve and bounded failure/endpoint cleanup remain. Added
  PAUSE_UNWIND_COMMITTED and PAUSE_NATIVE_CONTINUE trace events.
- Native continuation has a bounded geometry verification period; cancellation,
  lock, endpoint and stop still release owned resources. No repeated capture,
  brightness writer, or rendering resource is created for settled use.

## Validation

JUnit covers both slow directions, bounded jitter, stopped holds, midpoint native
selection, endpoint rearm, legacy and optional resume modes, rotation remaining
unlocked while native, delayed renderer delivery, frozen starting pose and normal
non-pause frame progression. Controller harness covers Home/apps, selected native
panels through midpoint, no scene restart, stale/wrong-panel unwind evidence,
native readiness, dissolve and cleanup. Full delivery build runs the JVM suite.

These checks validate code paths with a fake platform; smoothness and physical
panel behavior still need testing on the SM-F971U. No change is claimed to fix
the earlier framework restart or measured panel blackouts.
