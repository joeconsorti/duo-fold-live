# 3.0.4-alpha.26

- Starts the clean right cover mirror first, waits for its compositor transaction commit, then mounts the animated reflected left preview. The left view stays mounted throughout that preview session.
- Exclusion completion immediately triggers mirror setup; removes the old 500 ms startup polling delay and periodic mirror checks once attached. Failed setup still retries.
- The reflected secondary surface no longer participates in cover-source animation exclusion, so creating the left side cannot invalidate or rebuild the already-ready right mirror.
- Records the right-commit/left-start event for verification. A compositor commit is a software ordering signal, not a measurement of physical photon visibility.
- Keep Awake implementation unchanged. It is now documented as a known bug; further work is deferred. The lower-cost frosted reflected-left fallback is recorded for consideration only if this approach fails device testing.
