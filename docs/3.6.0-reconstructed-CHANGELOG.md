# Duo Fold Live 3.6.0 — stable

Promotes alpha.111's runtime to the public stable release, approved by the owner on November 11, 2026. The app identifies its reconstructed source as **3.6.0-reconstructed**.

- **Preview darkening removed:** restores the original frosted preview without the added center tint or edge shade. Existing blur, native readiness, preview dissolve, animation timing and handoff behavior remain unchanged.
- **Jitter protection retained:** both open and closed endpoints remain protected against small angle fluctuations.
- **Rotation recovery retained and documented:** the README now prominently explains the existing **Auto-rotate recovery → Repair auto-rotate** controls. Turn animation off, authorize Shizuku/root, run the repair, and test both screens before re-enabling animation.

Runtime source is identical to alpha.111 commit `8bc14e2828210ca8fa9cccb78d438a9eec9e19eb`. Promotion changes release metadata, documentation and build verification only. Alpha.111 passed 750 unit tests and 814 compiled-preview checks; public release CI reruns release tests, lint, renderer/controller checks, the compiled-preview harness, the manifest/privacy audit and signing verification before publishing.

In [issue #30](https://github.com/joeconsorti/duo-fold-live/issues/30#issuecomment-6516910817), briefer666 confirmed that rotation recovery worked. The rotation-restoration safeguards and manual repair are present in both public 3.5.9 and 3.6.0. This does not establish resolution on every handset/firmware, or of the separately reported Launcher 10 layout problem. Software checks are not on-device visual or orientation-sensor verification.

## Installation

The public APK uses **org.duofold.live** and the same permanent signing certificate as public 3.5.8/3.5.9, allowing an in-place update. VersionCode is at least **1366**.

Local reconstructed test builds use **org.duofold.live.test** and install separately. Disable the test app's animation before enabling the public app; settings do not automatically transfer between packages.

The alpha.107 rollback archive remains preserved. No Play Store publication is included.
