# Alpha.98 — Duo FPS reporting

Adds per-physical-panel, per-session submitted FPS and presentation-callback FPS to the direct Duo renderer diagnostics. Both normal status and status with health history already include those diagnostics; final session readings are retained after cleanup and in capture history. Inner/Cover and session ID are explicit.

Rates use (frame count - 1) / first-to-last frame interval; counts and measured milliseconds are printed beside the average. Startup before the first frame and idle time after the last frame are excluded. Stalls between frames remain included, without resetting the sample. Fewer than two frames with positive elapsed time is unmeasured. These are software session averages, not instantaneous FPS, optical FPS or actual panel refresh Hz. Each new renderer/session starts its own counters. Existing startup, delay and maximum gap metrics remain available.

No changes to animation, polling, capture, handoff or release behavior. Unit coverage checks independent rates, stalls, empty/short samples, session isolation and clock regression. Delivery uses the clean committed build workflow; handset FPS has not been measured here.
