# 3.0.4-alpha.9 — opt-in unlock flash capture

Diagnostic build; does not claim to fix the wallpaper flash.

In Choose & manage custom wallpaper, tap Start 30-second unlock capture. Wait for Capturing, return Home, lock and unlock once, then wait 35 seconds and tap Share unlock trace. Send the ZIP with whether the flash appeared and which screen was used.

- Requests a 30-second Perfetto session for SurfaceFlinger layers, transactions and shell transitions, with an 8 MiB ring buffer. Records source query, separate command stderr, configuration and boottime markers. Retail firmware may reject or omit data sources; a saved or nonempty trace is not proof that layer tracing succeeded.
- Includes up to six timed SurfaceFlinger proto/text snapshot pairs around screen events, with per-command time and output bounds. Snapshots are sequential, not an atomic or frame-by-frame observation. Reports truncation and capture errors explicitly.
- Retains up to 256 events with screen-on/off, unlock/keyguard state and photo draw/commit markers. Moves frame-commit registration before drawing, correcting the previous next-frame association.
- Capture is manual, stops automatically, and does not persist an enabled tracing setting. No screenshot, audio or input-event source is requested. Metadata can include app/window names. Only the latest completed export is retained. No trace upload occurs automatically.
- Keeps alpha.8 rendering and existing animation/rotation behavior. Temporarily suppresses routine window dumps during the explicit capture to reduce competing diagnostics. Capture overhead may still affect timing.

Validation: full release unit tests, lint and signed APK build in CI. On-device source availability and actual flash visibility require handset verification.
