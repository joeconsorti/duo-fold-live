## Changes

- The coordinated inner-left fade uses 60–85 degrees, reversible with the hinge.
  A cached black-to-transparent gradient extends over the first fifth of the
  physical right half (10% of the whole panel), with all four rotations mapped.
  The fully black left half still clips backdrop/shader work. The feather uses
  the existing blurred glass underneath and adds no second blur pass.
- New presentation windows start transparent. Only a geometry/exclusion-checked
  committed app frame permits their reveal. A late first animated buffer is
  withheld and replaced with plain screenshot coverage before reveal.
- Each physical panel gets an independent animation-start decision per session.
  The first animation commit must arrive within 500 ms and 30 degrees of the
  initial pose, before either endpoint. These are initial policy choices, not
  measured optimal device timings. Missing either limit skips that panel's
  animation for the session. A ready panel can still animate. Skipping is latched
  across quick reversals; active decisions survive logical-display remapping.
  A new panel starts at the current pose, without replaying old startup frames.
- Freshness uses the committed angle, not the newest drawn angle. A draw whose
  callback is pending cannot make an older committed pose appear current.
- Persistent preparation/steady-state commit stalls enter the existing native
  recovery path after 750 ms. That path restores task/native policy under retained
  coverage, requires fresh native readiness for early cleanup, and has a fixed
  1800 ms fallback. Reversals do not renew the deadline or allocate another shield.
  A missing buffer or actual blocked UI/compositor thread still cannot be repaired
  by this policy. No frame commit is treated as optical proof.
- Per-panel diagnostics report hidden/revealed state and animated/skipped status.
  The glass toggle remains opt-in; saved controls and alpha44's rendering defaults
  remain intact. Plain screenshot coverage still requires both panel commits
  before moving the task; allowing one panel to skip effects does not weaken that gate.
