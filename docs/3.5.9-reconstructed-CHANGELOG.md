# Duo Fold Live 3.5.9 — stable

Promotes alpha.109's runtime to the public stable release. This build uses reconstructed source, identified in the app version as **3.5.9-reconstructed**. The owner approved this promotion on November 9, 2026.

- **Duo Mode:** coordinated app snapshots animate across both displays, with native app placement and a return to an interactive screen when the hinge is held still.
- **Jitter protection at both endpoints:** the existing toggle now protects fully open as well as closed positions. With default thresholds, 170–172° fluctuations stay at the open endpoint; closing starts immediately at 169°, without an added timer. This prevents the reported 171°↔172° false animation starts.
- **Incoming frosted preview:** retains alpha.108's subtle center dimming and darker edges, fading away with the existing preview dissolve.
- **Existing controls retained:** adaptive resolution, appearance settings, motion glass and Live Screen Mode (Legacy).

This promotion changes version metadata, release publishing and documentation only, including synchronizing the bundled privacy text with the existing published diagnostic-retention paragraph. Runtime is unchanged from alpha.109. The local candidate passed 750 unit tests and the real-controller replay against a fake Android platform; public release CI additionally runs release tests, lint, renderer checks, manifest/privacy audit and signing verification. These are software checks, not proof of every handset or visible-panel behavior.

## Installation

The public APK uses **org.duofold.live** and the same permanent signing certificate as public 3.5.8, so existing public installations can update in place. Its versionCode is at least **1363**.

Local reconstructed test builds use the separate package **org.duofold.live.test**. The public build installs separately from those test builds. Disable the test app's animation before enabling the public app; settings do not automatically transfer between the two packages.

Alpha.107's archived local rollback remains preserved. This release does not publish a Play Store build or change Play Console state.
