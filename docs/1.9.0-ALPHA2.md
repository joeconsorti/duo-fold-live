# 1.9.0-alpha.2 — pre-release

Only the closing inner-screen cover mirror reveal changes. Previously both black layers used the primary display readiness/reveal clock, allowing the inner mirror to appear after its reveal had already elapsed. The inner secondary black layer now independently waits for its own ON state and a new successful mirror submission, plus the existing 120 ms settle interval, before using the existing fade duration. It never reduces the primary policy opacity. OFF restarts its wait; reopening cancels it. A missing mirror uses the existing 900 ms readiness timeout measured from secondary ON. Submission/ON samples are software events, not optical visibility proof.

Existing opening/cover fades, glass animation, slider defaults, performance settings, and keep-awake behavior are unchanged. Version code 1015; same signing identity. Test normal closing with continuity test off, especially a slow close through the handoff angle; confirm the mirrored cover view fades in on the inner panel. Hardware visual confirmation remains required.
